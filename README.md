# 🌮 CurieSchedule — Расписание, ДЗ & Admin Abuse

Интерактивный веб-сайт для школьного/студенческого расписания и контроля домашнего задания (ДЗ) с быстрым доступом к **DeepSeek AI**, **Яндекс Алисе** и **ГДЗ**, а также с секретным режимом **Admin Abuse** (светяшки, музыка, тако-дождь, смена расписания как захотите и мемный саундборд).

Проект полностью автономный (HTML, CSS, JS без внешних серверов), работает офлайн и идеально подходит для бесплатного хостинга на **GitHub Pages**!

---

## 🚀 Как выложить на GitHub и включить сайт для всех

### Шаг 1. Создайте репозиторий на GitHub
1. Зайдите на [github.com](https://github.com) и войдите в свой аккаунт.
2. Нажмите зелёную кнопку **"New"** (создать новый репозиторий).
3. Назовите его, например, `schedule` или `my-curie-schedule`.
4. Сделайте его **Public** (Публичным) и нажмите **"Create repository"**.

### Шаг 2. Загрузите файлы из этой папки
В терминале в папке проекта выполните команды:
```bash
git add .
git commit -m "Первый релиз: Расписание, ДЗ, AI и Admin Abuse"
git branch -M main
git remote add origin https://github.com/ВАШ_НИКНЕЙМ/ВАШ_РЕПОЗИТОРИЙ.git
git push -u origin main
```
*(Замените `ВАШ_НИКНЕЙМ` и `ВАШ_РЕПОЗИТОРИЙ` на ваши данные).*

### Шаг 3. Включите GitHub Pages (Бесплатный хостинг за 30 секунд!)
1. Откройте страницу вашего репозитория на GitHub.
2. Перейдите во вкладку **Settings** (Настройки) ⚙️ -> слева выберите раздел **Pages**.
3. В пункте **"Branch"** выберите ветку `main` (или `master`) и папку `/(root)`, затем нажмите **Save**.
4. Через 1-2 минуты GitHub выдаст вам готовую ссылку вида:  
   `https://ваш-никнейм.github.io/название-репозитория/`
5. Отправьте эту ссылку друзьям и одноклассникам! 🎉

## ⚡ Фишки и Возможности

### 📅 1. Расписание уроков
- Переключение по дням недели (Понедельник — Суббота).
- Автоматическая подсветка урока, который идет **прямо сейчас** по времени.
- Время, кабинеты, только нужные уроки (без учителей).
- **Защита от изменений**: обычные пользователи видят расписание в режиме «Только чтение». Добавлять, менять и удалять уроки может **только Администратор** через закрытую Admin-панель!
- Кнопки быстрого поиска ГДЗ и подсказок ИИ для каждого урока.

### 📝 2. Трекер Домашнего Задания и База Ответов (ДЗ)
- Удобный список задач с дедлайнами и отметками выполнения (`✓`).
- **💡 Загрузка ответов и решений (DeepSeek, Алиса ИИ, ГДЗ)**:
  - Админ может в 1 клик прикрепить к любому ДЗ готовый ответ из DeepSeek, Алисы или ссылку с решением из ГДЗ!
  - Любой ученик видит кнопку **«💡 Решение»** — по клику открывается подробный спойлер с ответом и кнопкой копирования.
- Быстрые кнопки прямо в карточке:
  - **🧠 DeepSeek Реши** — копирует готовый промпт в буфер обмена и открывает DeepSeek.
  - **🟣 Алиса Помоги** — копирует задачу для голосового ассистента Яндекса.
  - **📖 ГДЗ** — моментальный поиск готовых ответов к учебнику.

### 🔐 3. Система аккаунтов Firebase
- Вход и регистрация через **Email/Пароль** или **Google-аккаунт**.
- Разделение прав: **Ученик** vs **Админ**.
- Конфигурация в файле `js/firebase-config.js` — просто вставьте свои ключи из консоли Firebase.
- Если ключи не указаны, сайт автоматически работает в безопасном демонстрационном режиме!

### 🔗 4. Обмен с одноклассниками
- **Кнопка «Поделиться»**: генерирует специальную ссылку, в которую зашито всё текущее расписание. Тот, кто откроет ссылку, сразу получит ваше готовое расписание!
- **Экспорт / Импорт**: сохранение в `.json` файл и загрузка на любом устройстве.
- **LocalStorage**: все изменения автоматически сохраняются в браузере.

## 😈 Секретный режим «Admin Abuse» (Скрыт от обычных пользователей!)

Кнопка **«⚡ Admin Abuse»** в шапке сайта **скрыта по умолчанию** для всех обычных гостей и учеников!

### 🔑 Как активировать и войти:
1. Войдите под аккаунтом из списка `ADMIN_EMAILS` (кнопка появится автоматически), **ИЛИ**
2. Кликните **5 раз подряд** по логотипу с тако 🌮 в левом верхнем углу, **ИЛИ**
3. Напечатайте слово `taco` прямо на клавиатуре в любом месте, **ИЛИ**
4. Нажмите сочетание клавиш **`Ctrl + Shift + A`**.
5. Пароль: `1337` (также подходят `admin`, `taco` или секретная кнопка **«Я Взломщик»**).

### 🛠️ Что умеет Админ:
- ✏️ **Свободное редактирование (Live Edit)**: Включите тумблер и нажимайте прямо на названия уроков, кабинеты или учителей в расписании, чтобы изменить их на ходу!
- 🌈 **Светяшки (RGB Gamer Mode)**: Радужная неоновая переливающаяся подсветка всех карточек.
- 🪩 **Дискотека / Rave Party**: Цветомузыка и клубный свет прямо на экране.
- 🌮 **Дождь из Тако**: Бесконечный водопад летающих 3D тако и перчиков.
- 🌮 **Танцующий Тако-маскот**: Живой помощник в правом нижнем углу — нажимайте на него для мемов и звуков поедания.
