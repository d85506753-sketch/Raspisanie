⚡ Как включить синхронизацию для всех в Firebase Console (1 минута):

  1. Откройте Firestore в Firebase: Перейти в Firebase Console (raspisanie-3a39d)
  2. Нажмите кнопку «Создать базу данных» (Create database).
  3. Выберите регион (например eur3 (europe-west)) и нажмите «Далее».
  4. Выберите «Начать в тестовом режиме» (Start in test mode) или перейдите на вкладку «Правила» (Rules) и вставьте:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if request.auth != null && (
        request.auth.token.email == 'roganinstepan36@gmail.com' ||
        request.auth.token.email == 'steamvichsteam@gmail.com'
      );
    }
  }
}
